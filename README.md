## Sobre

Aplicação para gerenciamento de pizzaria desenvolvida em React.js com o Vite e Typescript, afim de fornecer um dashboard para o gerenciamento de pedidos e histórico de vendas.

## Requisitos e funcionalidades

- [x] Deve ser exibido total de receita mensal;
- [x] Deve ser exibido total de pedidos mensal;
- [x] Deve ser exibido total de pedidos diário;
- [x] Deve ser possível filtrar receita por perído e exibir em gráfico;
- [x] Deve ser exibido produtos populares;
- [x] Deve ser possível se autenticar;
- [x] Deve ser possível criar uma conta do restaurante;
- [x] Deve ser possível editar dados da conta;
- [x] Deve ser possível listar pedidos com paginação;
- [x] Deve ser possível alterar o status do pedido;
- [x] Deve ser possível filtrar pedidos por id;
- [x] Deve ser possível filtrar pedidos por nome do cliente;
- [x] Deve ser possível remover todos os filtros;
- [x] Deve ser possível exibir detalhes do pedido;
- [x] Deve ser possível alternar entre os temas claro, escuro ou do sistema;

## Como executar

Se estiver utilizando outro gerenciador de pacotes, basta trocar o `pnpm` por `npm`, `yarn`, etc.

### Pré-requisitos

- Node.js ( versão 14 ou superior )

Instalar as dependências do projeto.

```bash
pnpm install
```

### Localmente

Iniciar o servidor

```bash
pnpm dev
```

A aplicação estará disponível em http://localhost:5173.

### Testes

#### Unitários

```bash
pnpm test
```

#### E2E

```bash
pnpm test:e2e
```

Executa testes apresentando-os em uma interface

```bash
pnpm test:e2e:ui
```

#### Mock

```bash
pnpm dev:test
```

A aplicação estará disponível em http://localhost:50789.
